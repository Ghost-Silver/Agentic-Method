## 7. (HITL) 决策门

以下情况必须停止并请求人类确认：

1. 新增公共头文件或修改公共类。
2. 修改 ABI（虚函数表、enum 值、类大小、inline 函数语义）。
3. 修改序列化格式或错误码定义。
4. 删除已有公共 API。
5. 改变运算符重载语义。
6. 涉及跨模块或跨后端接口抽象。
7. 设计结果将固化为长期稳定 API。

### 7.1 HITL_REJECTED 记录

若人类否决了接口方案、ABI 策略或命名约定，必须按 master-prompt 要求记录完整 `(HITL_REJECTED)` 轨迹。
