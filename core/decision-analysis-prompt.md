# DECISION ANALYSIS PROMPT：{PROJECT_NAME} 多方案决策分析协议

> 适用：A/B/C 方案选型、是否引入新后端/新依赖、是否重构、技术债优先级排序、资源分配决策。

---

## 1. 阶段一：决策问题冻结 (R)

### 1.1 (CTX) 复述模板

```markdown
(CTX) 决策问题：<一句话>
(CTX) 决策类型：<不可逆 / 可逆 / 默认维持现状>
(CTX) 约束：<时间 / 资源 / 兼容性 / 性能 / 维护成本>
(CTX) 默认选项：<如果不做任何改变会怎样>
(CTX) 硬约束：<来自项目 memory 的约束>
```

### 1.2 证据收集清单

1. **每个选项的支持证据**：F0/F1 等级的事实，避免 F4 先验。
2. **每个选项的反对证据**：主动寻找反例和失败场景。
3. **历史类比**：近 30 天内相似决策的轨迹与结果。
4. **机会成本**：选择 A 意味着放弃 B 的什么收益。

---

## 2. 阶段二：选项生成与结构化 (T)

### 2.1 选项清单

```markdown
(BRANCH) 选项 A：...
(BRANCH) 选项 B：...
(BRANCH) 选项 C：维持现状（默认选项）
```

每个选项必须包含：

- 核心假设
- 收益（可量化）
- 风险（可量化）
- 成本
- 可逆性
- `(CONF: <level>, <证据统计>)`

### 2.2 评估维度

```markdown
| 维度 | 权重 | A | B | C |
|---|---|---|---|---|
| 正确性风险 | 0.3 | ... | ... | ... |
| 性能影响 | 0.25 | ... | ... | ... |
| 维护成本 | 0.2 | ... | ... | ... |
| 时间成本 | 0.15 | ... | ... | ... |
| 可逆性 | 0.1 | ... | ... | ... |
```

### 2.3 反事实分析 (CFC)

```markdown
(CFC) 若排除最佳选项，次优选项与最佳选项的差异是否可接受？
(CFC) 若每个选项的核心假设错误，损失分别是多少？
(CFC) 是否存在未被考虑的选项 D？
```

## 3. 阶段三：关键假设验证 (EXP)

### 3.1 每个选项的关键假设

```markdown
(EXP) 验证选项 A 的关键假设 H_A1
- 假设：...
- 方法：最小可行实验 / 原型 / 对照
- PREDICTION：若假设成立，观察到什么
- FALSIFICATION：若假设不成立，观察到什么
```

### 3.2 信息价值评估

```markdown
(EXP-AUDIT)
- 该实验能降低多少决策不确定性？
- 是否存在成本更低的替代实验？
- 实验结果是否能真正推翻某个选项？
```

## 5. 阶段五：对抗思考 (ADV)

### 5.1 反向推演

```markdown

- 哪个证据等级被高估了？
- 是否存在确认偏误？
```

## 7. (HITL) 决策门

以下情况必须停止并请求人类确认：

1. 决策将导致公共接口、ABI、序列化格式变更。
2. 决策将引入新依赖或升级关键依赖版本。
3. 决策将删除已有功能或降低测试覆盖。
4. 决策改变默认行为或用户可见语义。
5. 决策不可逆且成本较高。
6. 推荐选项的置信度为 low。
7. 决策结果将固化为人力/资源分配依据。

### 7.1 HITL_REJECTED 记录

若人类否决了推荐方案、评估维度或决策前提，必须按 master-prompt 要求记录完整 `(HITL_REJECTED)` 轨迹。
