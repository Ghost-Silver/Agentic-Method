# 反事实与消融实验必须遵循单一变量原则

**更新日期**：2026-07-29

## Rule

进行反事实（counterfactual）或消融（ablation）实验时，每次只改变一个变量。若因客观约束必须同时改变多个变量，必须显式声明 `COUNTERFACTUAL_RISK`、列出混淆变量，并说明为何仍能从观测中归因。

## When

- 需要判断“改动 A 是否导致结果 B”时；
- 需要量化某个同步点、编译选项、kernel 实现、调度策略的真实影响时；
- 需要排除其他因素干扰以建立因果边时。

## Because

多变量同时变化时，任何结果变化都可能来自多个因素的交互或协同，无法唯一归因。单一变量原则是科学方法中建立因果关系的最低要求；在系统性能优化和 Bug 排查中，违反该原则极易产生虚假因果结论，导致无效或有害的优化。

## Verification

- 在某后端同步点消融实验中，对 11 个显式同步点逐个独立删除，每次只改一个同步点，从而将性能变化归因到具体同步点。
- 修改核心数据结构 copy 语义时若同时改变设备迁移逻辑与梯度共享策略，则无法判断测试失败来自哪一项变更；必须分别验证。

## Failure cases

- 同时删除多个同步点并观测到性能变化，无法判断哪一个同步点最关键；
- 同时调整 batch size 与同步策略，无法解释吞吐变化的真正来源；
- 未声明混淆变量就给出性能排名，后续复现时可能因环境差异而失效。
