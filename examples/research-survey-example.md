# Example：研究调研适配

> 本示例展示如何将 `agentic-method` 适配到技术调研、文献综述或方案选型任务。

---

## 0. 任务定义 (CTX)

```markdown
(CTX) 调研目标：评估 {TOPIC} 领域的现有方案，为 {PROJECT_NAME} 的 {DECISION} 提供依据
(CTX) 时间范围：优先近 3 年，关键经典文献可放宽
(CTX) 输出形式：技术地图 + 方案对比矩阵 + 推荐 + 风险
```

---

## 1. 信息收集 (R)

1. 列出 {TOPIC} 的主流方案/框架/算法。
2. 收集每个方案的核心论文、官方文档、 benchmarks。
3. 标注来源类型：论文/官方文档/社区实践/博客。
4. 记录作者的潜在利益相关方偏见。

---

## 2. 来源可靠性审查

调用 `SOURCE_RELIABILITY_REVIEWER`：

```markdown
(SUB)
- 角色：SOURCE_RELIABILITY_REVIEWER
- 输入：<来源列表>
- 要求：识别单一来源断言、echo chamber、过时来源、利益相关方偏见
```

---

---

## 4. 竞争性假设 (BRANCH)

```markdown
(BRANCH) H1: 方案 A 是当前最优选择，因为它在 {METRIC} 上表现最好。
(BRANCH) H2: 方案 B 更适合 {PROJECT_NAME}，因为它与现有架构集成成本最低。
(BRANCH) H3: 两种方案都不适合，需要自研或混合方案。
```

---

## 5. 推荐与验证路径

```markdown
(M) 推荐方案：
- 理由：
- 关键假设：
- 验证实验（如果采纳）：
- 回滚条件：
- (CONF: <level>, <证据统计>)
```

---

## 6. 风险声明

```markdown
(COUNTERFACTUAL_RISK)
- 本推荐基于 {ASSUMPTIONS}。
- 若这些前提不成立，推荐可能失效。
- 混淆变量：{LIST}
```
